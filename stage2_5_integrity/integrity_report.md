## Phase C — 数据核查(Data Verification)

**方法**:核查论文中一切数值、图表、公式的来源与可复现性。

**核查对象**:本文不含真实协议实测数据。论文唯一的定量产物是第 7 章成本模型及其衍生图表:
- 解析模型:净优势 ≈ Δ_save − ρ·Δ_recover;临界点 ρ* = Δ_save/Δ_recover
- code/dag_bft_model.py:解析函数 + Monte Carlo 仿真(2000 轮 × 500 trial)
- Figure 1-3:由 code/make_figures.py 从上述模型生成

**核验结果**:
1. **公式自洽性**:ρ* = Δ_save/Δ_recover 由净优势 = 0 解出,代数正确 ✓
2. **仿真-解析一致性**:Monte Carlo 仿真均值与解析值收敛,误差 <0.5% ✓(仿真自检已通过)
3. **图表可复现性**:三图均可由 code/ 目录脚本一键重生 ✓
4. **关键诚实标注**:论文与 code/README.md 均明确声明 —— 该模型及仿真是"解析模型的数值演示(numerical illustration),不是真实协议实测"。**未将其冒充为实验验证。**

**发现**:无数据造假、无 p-hacking、无选择性报告。模型的范围限制已在正文(第 7 章范围声明)与代码文档中双重诚实标注。
**Phase C 裁决:PASS**

## Phase D — 原创性核查(Originality Check)

**方法**:抽查正文 ≥30% 段落,核查是否存在未标注的直接翻译、贴近改写(close paraphrase)、或对单一来源的过度依赖。

**核查结果**:
- **核心论点原创**:中心主张(去认证 = 结构性替换;深层设计轴 = availability-enforcement;条件性延迟优势 + 临界 ρ*)为本文经 Stage 1 socratic 推演构造,非来自任一被引文献的现成结论。检索未发现等价表述的既有文献。
- **无直接翻译**:论文未出现对英文文献的逐句翻译充当原创分析。术语英文保留属约定写法,非翻译规避。
- **无贴近改写**:抽查第 1、3、5、7、8 章段落,转述均经过实质性重构与综合,非换词改写。
- **无单源依赖**:每章论证均交叉引用多篇文献;三不变量分析框架由多源综合而成。

**发现**:论文为原创分析性写作,不构成抄袭或拼接式综述。
**Phase D 裁决:PASS(ORIGINAL)**
