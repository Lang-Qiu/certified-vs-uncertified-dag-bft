# 多验证者实验留存清单

本清单用于记录阶段 6+9 多验证者实验的证据采集、指标抽取与 Manifest 留存要求。当前文件是初始模板，后续运行 `collect_evidence.py` 生成的 manifest 会注册具体产物并持续更新留存记录。

## 计划留存的证据类型

- RPC 探测 JSONL：用于提取 `rpc_ok` 延迟、RPC 可用性样本。
- Workload JSONL：用于区分计划事件、成功交易与失败交易；计划事件不得伪造成成功交易。
- Fault timeline JSONL：用于记录故障注入、恢复事件和恢复耗时。
- Container state 日志：用于保存容器状态、运行日志与辅助诊断材料。
- Manifest JSON：用于记录每个产物的相对路径、SHA-256、字节数、来源、类型与注册时间。

## 留存原则

- 只登记已经存在于 run 目录中的证据文件，不在采集阶段调用 Docker 或重新执行实验。
- Manifest 中的相对路径以 run root 或指定 root 为基准，校验时必须能定位到真实文件。
- 后续更新应以 manifest 注册结果为准；本模板不表示实验已经完成。
