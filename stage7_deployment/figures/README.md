# Stage 2 Figures

Figures in this directory must be generated from files under
`stage7_deployment/data/derived/`.

Each figure must have:

- PNG preview.
- PDF export suitable for LaTeX insertion.
- A manifest entry in `stage7_deployment/data/manifest.json`.
- A visible source label of `real-deployment` when the figure uses Stage 2 data.

Stage 2 figures must not be written into `final/final_paper.md` unless Stage 3
explicitly approves paper integration.
