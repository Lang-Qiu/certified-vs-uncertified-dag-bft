## 评审组配置卡(5 位独立评审人)

### EIC — 主编(期刊契合度 / 原创性 / 显著性)
**身份**:某顶级分布式计算会议(PODC/DISC 级)的资深领域主席,长期处理共识协议的理论与系统论文。**评审偏好**:重视论文是否提出一个"值得记住的判断",对纯增量协议优化容忍度低,对批判性/重构性论文持开放但严格的态度——会追问"这个 reframing 是否真的改变了读者的思考方式"。

### Reviewer 1 — 方法论(research design / 形式化严格性 / 可复现性)
**身份**:分布式系统理论与形式化方法专家,熟悉 FLP、部分同步、不可能性证明技术。**关注点**:第 3 章受控 minimal-pair 框架是否真正隔离了单一变量;C1-B 三分判据与 C1-C 双判据是否可操作、可证伪;**命题 1 的证明是否严格**(敌手构造、模型假设);第 7 章成本模型的有效性边界;Monte Carlo 仿真到底验证了什么、不验证什么。

### Reviewer 2 — 领域(文献覆盖 / 理论框架 / 领域贡献)
**身份**:DAG-BFT 共识协议方向的活跃研究者,对 DAG-Rider / Narwhal / Tusk / Bullshark / Mysticeti / Cordial Miners / Adelie 的协议细节有第一手了解。**关注点**:三不变量分解是否忠实于 RBC 性质;对各协议机制的描述是否准确(尤其 Mysticeti 提交规则、Adelie 的攻击面);第 2.7 节"研究空白"声明是否成立,是否遗漏关键文献;corpus C 的选取是否有代表性偏差。

### Reviewer 3 — 跨视角(跨学科关联 / 实践影响 / 挑战根本假设)
**身份**:兼做共识测量与 MEV / 排序公平性的研究者,偏经验与系统部署视角。**关注点**:条件化结论对真实协议设计者是否 actionable;第 8.5 节 MEV 延伸是否站得住、还是过度延伸;全文无真实实测这一点对贡献的实际影响;深层轴对 benchmark 设计者的指导是否具体。

### Devil's Advocate — 魔鬼代言人(核心论点挑战 / 逻辑谬误 / 最强反论)
**专责**:构造针对中心主张的最强反论。重点质疑:(1)"结构性替换"是否是一个真命题,还是把"显然的事"包装成发现;(2)命题 1 是否过于平凡(trivial)——是否只是 split-brain 攻击的换皮;(3)成本模型 净优势 ≈ Δ_save − ρ·Δ_recover 是否简化到接近同义反复;(4)贡献 C 的"深层轴"是 genuine reframing 还是 relabeling;(5)corpus C 选取与 confirmation bias;(6)"So what?" 检验。

## 课程作业评分量规校准(用户要求新增)

本次评审在标准同行评审之外,叠加一层**课程评分量规校准**。每位评审人除常规报告外,须对其责任维度给出 0–100 量规分与依据;editorial_synthesizer 在 Phase 2 汇编一张《量规对照评分卡》。

| 量规维度 | 权重 | 主责评审人 | 副责评审人 | 校准要点 |
|----------|------|-----------|-----------|----------|
| 前沿性 | 15% | EIC | R2 领域 | 选题是否触及 DAG-BFT 当前最活跃的争论;文献是否覆盖 2024–2025 最新协议(Mysticeti/Mahi-Mahi/Sailfish/Adelie/Shoal++) |
| 完整性 | 25% | R2 领域 | R1 方法论 | RQ→SubRQ→各章是否闭环;论证链是否无断点;反论与局限是否齐备 |
| 规范性 | 25% | R1 方法论 | EIC | 形式化命题表述、判据可操作性、引用规范、图表规范、声明完整性 |
| 创新能力 | 20% | Devil's Advocate | R3 跨视角 | 贡献 A/B/C 是否实质创新;深层轴是 genuine reframing 还是 relabeling;"结构性替换"是否真命题 |
| 写作能力 | 15% | R3 跨视角 | EIC | 结构清晰度、术语一致性、论证可读性、中英文摘要质量 |

**校准规则**:
1. 量规分须证据驱动,与评审报告中的 strengths/weaknesses 一致,不得为避免冲突而虚高(对标 Anti-Pattern #5 sycophantic inflation)。
2. 每位评审人在报告末尾追加「量规维度评分」小节,仅就其主责/副责维度打分并给一句话依据。
3. Phase 2 综合者据 5 份报告汇编《量规对照评分卡》,给出每维度的合议分(权重加权)与"距离满分的关键扣分项"。
4. 量规分服务于课程作业目标,**不替代**编辑决定(Accept/Minor/Major);二者并列呈现。

## ⚠️ 评审铁律(执行约束)
1. 5 位评审人独立评审,互不交叉参考。
2. 综合者(editorial_synthesizer)不得虚构评审意见,每条综合意见须可追溯到具体评审报告。
3. **若 Devil's Advocate 发现 CRITICAL 问题,编辑决定不得为 Accept。**
4. 评审人只读不改:全部评审产出为独立文档,绝不修改论文本体。
